## 📖 About

A modern, immersive **3D developer portfolio** built with Next.js 16, React Three Fiber, and Tailwind CSS v4. Designed to showcase projects, skills, and experience with a premium, interactive user experience.

> 🎯 **Live:** [3d-portfolio-seven-beta-14.vercel.app](https://3d-portfolio-seven-beta-14.vercel.app/)

---

## ✨ Features

### 🎭 Immersive 3D Experience
- Interactive 3D scenes powered by **React Three Fiber** & **Three.js**
- Smooth scroll-based animations with **Framer Motion**
- Custom shaders and WebGL effects
- Optimized for performance (60 FPS on mid-range devices)

### 🎨 Premium UI/UX
- **Glass morphism** cards and gradients
- **Dual theme** — light + dark mode with system preference
- Micro-interactions and hover effects
- Fully responsive (mobile → 4K displays)
- Custom Poppins typography

### 📂 Complete Portfolio Sections
- **Hero** — Animated intro with live stats
- **About** — Bio, philosophy, current focus
- **Skills** — Frontend, Backend, DevOps, Design (with proficiency bars)
- **Services** — 6 service offerings with tech tags
- **Featured Work** — 6 showcased projects
- **Experience** — Career timeline with achievements
- **Journey** — Education & milestones
- **Open Source** — GitHub contributions
- **Testimonials** — Client feedback carousel
- **Contact** — Direct email + socials

### ⚡ Performance
- **Next.js 16** App Router with Turbopack
- **AVIF/WebP** image optimization
- **Code splitting** for 3D scenes
- Lazy loading for below-the-fold content
- Optimized for **Lighthouse 90+**

### ♿ Accessibility
- ARIA labels and keyboard navigation
- `prefers-reduced-motion` support
- Semantic HTML
- WCAG AA contrast ratios
